# Praksis IS-302 Nettside

En GitHub Pages nettside for dokumentasjon av praksis med ukentlige logger.

## Struktur

```
├── index.html           # Forsiden
├── oppgaver.html        # Oppgaver og mål
├── logger.html          # Oversikt over logger
├── style.css            # Styling
├── script.js            # JavaScript
├── logs/
│   ├── uke-1/
│   │   └── index.html
│   ├── uke-2/
│   │   └── index.html
│   └── ...
└── README.md
```

## Slik bruker du denne nettsiden

### 1. Rediger oppgavene
Åpne `oppgaver.html` og endre oppgavene under "Oppgaver og Mål" med dine faktiske oppgaver.

### 2. Legg til ukentlige logger
For hver uke:
- Opprett en ny mappe i `logs/` som `uke-1`, `uke-2`, osv.
- Kopier malen fra `logs/uke-1/index.html` til din nye mappe
- Rediger filen med din ukentlige logg

### 3. Publiser på GitHub Pages
1. Gå til Settings > Pages i repoet ditt
2. Velg "Deploy from a branch"
3. Velg `main` branch og `/ (root)` folder
4. Nettsiden vil være tilgjengelig på: `https://haakonhalvors1.github.io/Praksis-Skatteetaten/`

## Tips for dokumentasjon

Hver ukelog bør inneholde:
- ✅ Hva du gjorde
- ✅ Læringspunkter
- ✅ Utfordringer og løsninger
- ✅ Planlagt for neste uke
- ✅ Personlig refleksjon

God tur med praktikken! 📚
